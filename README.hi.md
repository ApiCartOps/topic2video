# topic2video

किसी भी तकनीकी या वैज्ञानिक विषय को पूरी तरह कोड से बनाए गए, आवाज़ के साथ चलने वाले मोशन-ग्राफ़िक्स एक्सप्लेनर वीडियो में बदलें।

कोई विषय (या कोई लेख) दें, और यह **चीनी या अंग्रेज़ी** में एक मौलिक एक्सप्लेनर वीडियो बनाता है: काला कैनवास, स्टार-फ़ील्ड या डॉट-फ़ील्ड बैकड्रॉप, बैंगनी (purple) जोर वाले सफ़ेद लाइन ग्राफ़िक्स, TTS वॉइसओवर, सबटाइटल, और एक अध्याय प्रगति-पट्टी। हर फ़्रेम [Remotion](https://www.remotion.dev/) (React) से बनता है, इसलिए वीडियो सोर्स के रूप में दोबारा बनाया और संपादित किया जा सकता है।

यह रिपॉज़िटरी एक **Claude Code skill** (`SKILL.md`) है, साथ में संदर्भ दस्तावेज़, एजेंट प्रोटोकॉल, और एक कम्पाइल होने योग्य Remotion प्रोजेक्ट टेम्पलेट।

## रिपॉज़िटरी में क्या है

| पथ | सामग्री |
|---|---|
| `SKILL.md` | skill का प्रवेश बिंदु: मुख्य नियम, चार उपयोगकर्ता पुष्टि-बिंदु, आठ-चरणीय कार्यप्रवाह, फ़ाइल सूची |
| `template/` | कम्पाइल होने योग्य Remotion 4 प्रोजेक्ट: मोशन लाइब्रेरी, UI प्रिमिटिव, अध्याय/HUD/ओवरले कंपोनेंट, फ़ॉन्ट (OFL), और TTS, स्टोरीबोर्ड रेंडरिंग, स्टिल, प्रीव्यू, रेंडर और जाँच के स्क्रिप्ट |
| `reference/` | स्टाइल गाइड, मोशन शब्दावली, संरचना और प्रकाश नियम, नैरेशन/स्टोरीबोर्ड प्रारूप, रिसर्च ब्रीफ़, एजेंट प्रॉम्प्ट और बिल्ड/QC प्रोटोकॉल, सीखे गए सबक |
| `examples/rag/` | एक पूरा नमूना वीडियो, *RAG and Knowledge Bases* (4′35″, चीनी नैरेशन): रिसर्च, नैरेशन, स्टोरीबोर्ड, हर शॉट का सोर्स कोड, QC रिपोर्ट और फ़्रेम। इसे गुणवत्ता मानदंड के रूप में उपयोग करें |
| `examples/contrast/` | संरचना और प्रकाश नियमों को व्यवहार में दिखाने वाले पहले/बाद फ़्रेम के जोड़े |

## आवश्यकताएँ

- Claude Code (skill कार्यप्रवाह चलाने के लिए)
- Node.js और npm (Remotion प्रोजेक्ट)
- Python 3 (TTS, स्टोरीबोर्ड और मेट्रिक्स स्क्रिप्ट)
- हर वीडियो प्रोजेक्ट के लिए लगभग 2 GB डिस्क स्थान

TTS इंजन सेटअप के लिए `template/scripts/tts_build.py` की हेडर टिप्पणी देखें।

## त्वरित शुरुआत

1. इस फ़ोल्डर को वहाँ रखें जहाँ Claude Code skills लोड करता है (उदाहरण: `~/.claude/skills/anything2explainer`)।
2. Claude Code से एक्सप्लेनर माँगें, जैसे *"Make a 4-minute explainer video about vector databases, in Chinese."*
3. Claude `SKILL.md` का पालन करता है: वह अवधि और भाषा पूछता है, फिर पूरा वीडियो बनाने से पहले पुष्टि-बिंदुओं (नैरेशन, आवाज़, और 30-सेकंड का प्रीव्यू) पर रुकता है।

टेम्पलेट से हाथ से प्रोजेक्ट बनाने के लिए:

```bash
template/scripts/new_project.sh <work-dir> <slug>
cd <work-dir>
npm run studio            # प्रीव्यू के लिए Remotion studio खोलें
```

## श्रेय और तृतीय-पक्ष घटक

- **दृश्य प्रेरणा**: इसका रूप Douyin अकाउंट "图灵宇宙" (Turing Universe) से प्रेरित है। सभी फ़्रेम कोड से बनाए गए हैं; किसी अन्य वीडियो के फ़ुटेज या फ़्रेम का उपयोग नहीं किया गया है।
- **फ़ॉन्ट**: Noto Sans SC, Orbitron, Exo 2 और Audiowide, सभी SIL Open Font License 1.1 के अंतर्गत। देखें [`template/public/fonts/LICENSE.md`](template/public/fonts/LICENSE.md)।
- **रेंडरिंग**: [Remotion](https://www.remotion.dev/)। Remotion का अपना लाइसेंस है, OSI-अनुमोदित नहीं। इसकी शर्तों के अनुसार कुछ व्यावसायिक उपयोग के लिए कंपनी लाइसेंस चाहिए, इसलिए व्यवसाय में उपयोग से पहले इन्हें जाँच लें।
- **आवाज़ें**: डिफ़ॉल्ट चीनी आवाज़ `edge-tts` का उपयोग करती है, जो Microsoft की ऑनलाइन स्पीच सेवा को कॉल करती है और उसकी शर्तों के अधीन है। डिफ़ॉल्ट अंग्रेज़ी आवाज़ `kokoro-82m` का उपयोग करती है, जो Apache-2.0 है। आप अपनी ऑडियो फ़ाइल भी दे सकते हैं।
