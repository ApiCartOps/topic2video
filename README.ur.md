# topic2video

کسی بھی تکنیکی یا سائنسی موضوع کو مکمل طور پر کوڈ سے بنائی گئی، آواز کے ساتھ چلنے والی موشن گرافکس وضاحتی ویڈیو میں بدلیں۔

کوئی موضوع (یا کوئی مضمون) دیں، اور یہ **چینی یا انگریزی** میں ایک اصل وضاحتی ویڈیو بناتا ہے: سیاہ کینوس، اسٹار فیلڈ یا ڈاٹ فیلڈ پس منظر، جامنی (purple) زور والی سفید لائن گرافکس، TTS وائس اوور، سب ٹائٹلز، اور باب کی پیش رفت کی پٹی۔ ہر فریم [Remotion](https://www.remotion.dev/) (React) سے بنتا ہے، اس لیے ویڈیو کو سورس کے طور پر دوبارہ بنایا اور ترمیم کیا جا سکتا ہے۔

یہ ریپوزٹری ایک **Claude Code skill** (`SKILL.md`) ہے، ساتھ میں حوالہ جاتی دستاویزات، ایجنٹ پروٹوکول، اور ایک قابلِ کمپائل Remotion پروجیکٹ ٹیمپلیٹ۔

## ریپوزٹری میں کیا ہے

| راستہ | مواد |
|---|---|
| `SKILL.md` | skill کا داخلی نقطہ: بنیادی اصول، صارف کے چار تصدیقی مراحل، آٹھ مرحلوں کا ورک فلو، فائل فہرست |
| `template/` | قابلِ کمپائل Remotion 4 پروجیکٹ: مشترکہ موشن لائبریری، UI پرimitives، باب/HUD/اوورلے کمپوننٹس، فونٹس (OFL)، اور TTS، اسٹوری بورڈ رینڈرنگ، اسٹلز، پیش نظارے، رینڈر اور جانچ کے اسکرپٹس |
| `reference/` | اسٹائل گائیڈ، موشن الفاظ، ترکیب اور روشنی کے اصول، بیانیہ/اسٹوری بورڈ کی شکل، ریسرچ بریف، ایجنٹ پرامپٹس اور بلڈ/QC پروٹوکولز، سیکھے گئے اسباق |
| `examples/rag/` | ایک مکمل نمونہ ویڈیو، *RAG and Knowledge Bases* (4′35″، چینی بیانیہ): ریسرچ، بیانیہ، اسٹوری بورڈ، ہر شاٹ کا سورس کوڈ، QC رپورٹس اور فریمز۔ اسے معیار کے پیمانے کے طور پر استعمال کریں |
| `examples/contrast/` | ترکیب اور روشنی کے اصولوں کو عملی طور پر دکھانے والے پہلے/بعد فریم کے جوڑے |

## ضروریات

- Claude Code (skill ورک فلو چلانے کے لیے)
- Node.js اور npm (Remotion پروجیکٹ)
- Python 3 (TTS، اسٹوری بورڈ اور میٹرکس اسکرپٹس)
- ہر ویڈیو پروجیکٹ کے لیے تقریباً 2 GB ڈسک جگہ

TTS انجن کی سیٹ اپ معلومات کے لیے `template/scripts/tts_build.py` کا ہیڈر تبصرہ دیکھیں۔

## فوری آغاز

1. اس فولڈر کو وہاں رکھیں جہاں Claude Code skills لوڈ کرتا ہے (مثال: `~/.claude/skills/anything2explainer`)۔
2. Claude Code سے وضاحتی ویڈیو مانگیں، جیسے *"Make a 4-minute explainer video about vector databases, in Chinese."*
3. Claude `SKILL.md` پر عمل کرتا ہے: وہ دورانیہ اور زبان پوچھتا ہے، پھر پوری ویڈیو بنانے سے پہلے تصدیقی مراحل (بیانیہ، آواز، اور 30 سیکنڈ کا پیش نظارہ) پر رکتا ہے۔

ٹیمپلیٹ سے ہاتھ سے پروجیکٹ بنانے کے لیے:

```bash
template/scripts/new_project.sh <work-dir> <slug>
cd <work-dir>
npm run studio            # پیش نظارے کے لیے Remotion studio کھولیں
```

## اعتراف اور تیسرے فریق کے اجزاء

- **بصری الہام**: اس کا انداز Douyin اکاؤنٹ "图灵宇宙" (Turing Universe) سے متاثر ہے۔ تمام فریمز کوڈ سے بنائے گئے ہیں؛ کسی دوسری ویڈیو کی فوٹیج یا فریمز استعمال نہیں کیے گئے۔
- **فونٹس**: Noto Sans SC، Orbitron، Exo 2 اور Audiowide، سب SIL Open Font License 1.1 کے تحت۔ دیکھیں [`template/public/fonts/LICENSE.md`](template/public/fonts/LICENSE.md)۔
- **رینڈرنگ**: [Remotion](https://www.remotion.dev/)۔ Remotion کا اپنا لائسنس ہے، OSI سے منظور شدہ نہیں۔ اس کی شرائط کے مطابق کچھ کاروباری استعمال کے لیے کمپنی لائسنس درکار ہے، اس لیے کاروبار میں استعمال سے پہلے انہیں ضرور دیکھ لیں۔
- **آوازیں**: ڈیفالٹ چینی آواز `edge-tts` استعمال کرتی ہے، جو Microsoft کی آن لائن اسپیچ سروس کو کال کرتی ہے اور اس کی شرائط کے تابع ہے۔ ڈیفالٹ انگریزی آواز `kokoro-82m` استعمال کرتی ہے، جو Apache-2.0 ہے۔ آپ اپنی آڈیو فائل بھی فراہم کر سکتے ہیں۔
