# topic2video

حوّل أي موضوع تقني أو علمي إلى فيديو شرح بالرسوم المتحركة مع تعليق صوتي، مرسوم بالكامل بالكود.

أعطه موضوعًا (أو مقالًا) فينتج فيديو شرح أصليًا باللغة **الصينية أو الإنجليزية**: خلفية سوداء، وخلفية بنجوم أو بنقاط، ورسومات خطية بيضاء مع تمييز بنفسجي، وتعليق صوتي TTS، وترجمات، وشريط تقدم للفصول. كل إطار يُرسم بـ [Remotion](https://www.remotion.dev/) (React)، لذلك يمكن إعادة إنتاج الفيديو وتحريره كمصدر.

هذا المستودع هو **Claude Code skill** (`SKILL.md`)، إضافة إلى وثائق المرجع وبروتوكولات الوكلاء وقالب مشروع Remotion قابل للترجمة الذي يستخدمه.

## محتويات المستودع

| المسار | المحتوى |
|---|---|
| `SKILL.md` | نقطة الدخول للمهارة: القواعد الأساسية، ونقاط التأكيد الأربع للمستخدم، وسير عمل من ثماني مراحل، وفهرس الملفات |
| `template/` | مشروع Remotion 4 قابل للترجمة: مكتبة الحركة المشتركة، ومكونات الواجهة، ومكونات الفصول وHUD والتراكب، والخطوط (OFL)، وسكربتات TTS وعرض لوحة القصة والصور الثابتة والمعاينات والعرض والفحوص |
| `reference/` | دليل الأسلوب، ومفردات الحركة، وقواعد التكوين والإضاءة، وصيغة السرد/لوحة القصة، وموجز البحث، ومطالبات الوكلاء وبروتوكولات البناء/QC، والدروس المستفادة |
| `examples/rag/` | فيديو نموذجي كامل، *RAG and Knowledge Bases* (4′35″، سرد صيني): البحث والسرد ولوحة القصة وكود كل لقطة وتقارير QC والإطارات. استخدمه كمعيار للجودة |
| `examples/contrast/` | أزواج إطارات قبل/بعد توضح قواعد التكوين والإضاءة عمليًا |

## المتطلبات

- Claude Code (لتشغيل سير عمل المهارة)
- Node.js وnpm (مشروع Remotion)
- Python 3 (سكربتات TTS ولوحة القصة والمقاييس)
- حوالي 2 GB من مساحة القرص لكل مشروع فيديو

راجع التعليق في رأس الملف `template/scripts/tts_build.py` لإعداد محرك TTS.

## بداية سريعة

1. ضع هذا المجلد في المكان الذي يحمّل منه Claude Code المهارات (مثال: `~/.claude/skills/anything2explainer`).
2. اطلب من Claude Code فيديو شرح، مثل *"Make a 4-minute explainer video about vector databases, in Chinese."*
3. يتبع Claude الملف `SKILL.md`: يسأل عن المدة واللغة، ثم يتوقف عند نقاط التأكيد (السرد والصوت ومعاينة مدتها 30 ثانية) قبل بناء الفيديو كاملًا.

لبناء مشروع يدويًا من القالب:

```bash
template/scripts/new_project.sh <work-dir> <slug>
cd <work-dir>
npm run studio            # افتح Remotion studio للمعاينة
```

## الإسناد والمكونات الخارجية

- **الإلهام البصري**: الشكل مستوحى من حساب Douyin "图灵宇宙" (Turing Universe). كل الإطارات مرسومة بالكود؛ لا تُستخدم أي لقطات أو إطارات من فيديوهات أخرى.
- **الخطوط**: Noto Sans SC وOrbitron وExo 2 وAudiowide، وكلها بموجب SIL Open Font License 1.1. انظر [`template/public/fonts/LICENSE.md`](template/public/fonts/LICENSE.md).
- **العرض**: [Remotion](https://www.remotion.dev/). لدى Remotion ترخيصه الخاص، وليس معتمدًا من OSI. تشترط شروطه ترخيص شركة لبعض الاستخدامات التجارية، فتحقق منها قبل الاستخدام في عمل تجاري.
- **الأصوات**: يستخدم الصوت الصيني الافتراضي `edge-tts`، الذي يتصل بخدمة الكلام عبر الإنترنت من Microsoft ويخضع لشروطها. يستخدم الصوت الإنجليزي الافتراضي `kokoro-82m`، وهو بترخيص Apache-2.0. يمكنك أيضًا تقديم ملف صوتي خاص بك.
